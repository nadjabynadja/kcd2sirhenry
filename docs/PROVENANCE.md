# Asset, translation, and voice provenance

This is a concise working record, not a legal treatise. Expand it when the
original production notes are recovered.

## Project-authored material

- Narrative direction, replacement dialogue choices, gameplay design, custom
  table records, documentation, and repository tooling: Nadja.
- The mod is unofficial and is not endorsed by Warhorse Studios or PLAION.

## Game-derived material

The release archives contain complete localization and gameplay-table snapshots
derived from *Kingdom Come: Deliverance II*. Names, identifiers, original text,
schemas, icons, and other game material remain the property of their respective
rights holders and are included only for operation as a non-commercial fan mod.

## Translations

The release contains replacement text for 16 game languages. The recovered
bundle does not identify the translation tools, models, translators, or human
review status used for each language. That information should be added to the
future localization manifest during source recovery; it is not guessed here.

## Voice-over

The release contains 300 replacement Ogg/Vorbis lines in each of 16 languages.
The mod manifest describes them as cloned voice-over. The recovered bundle does
not identify the voice model/service, source recordings, generation settings,
or review process. Record those facts in `src/voice/manifest.tsv` when the
production notes are available.

Do not represent generated lines as new performances by the original actors.
